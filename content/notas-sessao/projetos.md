## Projetos para a Universidade

### 1. IA de Terminal (IA CLI)
Uma IA que vive no terminal — a camada mais interna do computador (a "caixa preta de Matrix"). Configurada para ver e interagir com os próprios arquivos. Como conversar com o próprio computador.

→ Usado como projeto para **Testes de Software** (Prof. Prof. X)

### 2. Banco de Dados Java + Jogos
Um CRUD com verificação de e-mail, criação de conta, login. O professor pediu só o banco de dados. Foram feitos dois jogos de bônus em cima. Um deles é um **jogo secreto** — só acessível depois de terminar o primeiro. Há um chefe.

→ Usado como projeto para **Programação Orientada ao Objeto** (Prof. Prof. X)

### 3. LibreBase
Banco de dados construído do zero com código aberto. Ver [[sistemas-de-conhecimento#librebase]].

→ Usado como projeto para **Implantação de Banco de Dados** (Prof. Prof. Y)

### 4. Lógica de Programação (Prof. Z)
A disciplina mais fácil — zero aulas juntos até o momento (ela faltou na primeira, faltei na segunda). Projeto ainda indefinido. Será o mais simples dos quatro. Sem prioridade por enquanto.

O conteúdo que o Prof. Prof. X pede em Programação Orientada ao Objeto também envolve banco de dados — fora da ementa esperada. Tudo que estava sendo estudado de forma autônoma virou disciplina formal.

## IA como Suplemento

A IA não faz o projeto. Ela não conhece o projeto tão bem quanto quem o construiu — não sabe o *porquê* de cada decisão. A fundação e as decisões de fechamento são feitas manualmente. A IA lida com as partes repetitivas.

Fazer tudo manualmente em contexto profissional e de estágio seria reinventar a roda. Mas entender *como* as coisas funcionam de verdade — isso continua sendo feito.
